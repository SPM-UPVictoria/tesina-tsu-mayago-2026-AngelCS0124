\subsection{Desarrollo del sistema}
\label{sec:desarrollo_sistema}

En esta seccion se describe la arquitectura tecnica del sistema, los patrones de diseño utilizado y la estructura general del código.

\subsubsection{Arquitectura tecnica del sistema}
\label{subsec:arquitectura_tecnica_sistema}

Se trata de una arquitectura monolitica, en la cual el backend y el frontend se encunetran en un mismo proyecto, esto debido a que el proyecto es de tamaño pequeño y no se requiere de una arquitectura distribuida o algo similar.

Para entrar mas a detalle con la arquitectura técnica del sistema, se puede dividir en los siguientes puntos con sus respectivas descripciones:

\begin{itemize}
    \item \textbf{Backend:} El backend fue desarrollado en el framework Laravel, en su versión de Laravel 13, esto basado en PHP 8.3. Este framework facilita diversos aspectos durante el desarrollo como la gestion de las rutas, la autenticacion, la gestion de roles, la interaccion con la base de datos. Todos los aspectos mencionados y mas han sido de gran ayuda para el correcto desarrollo del sistema.
    \item \textbf{Frontend:} El frontend fue desarrollado con React, una libreria de JavaScript para la construcción de interfaces de usuario, comunicada con el backend a traves de Inertia.js, lo que permite mantener la experiencia de una aplicación de pagina única sin necesidad de construir una API separada. 
    \item \textbf{Base de datos:} La persistencia de datos fue manejada con PostgreSQL, un sistema de gestión de bases de datos relacional. Su integración con Laravel facilita la definición del esquema mediante migraciones versionadas.
    \item \textbf{Caché y sesiones:} Las sesiones de usuario y el caché del sistema son administrados mediante Redis, mejorando el rendimiento general del sistema en estas operaciones.
    \item \textbf{Integración con IA:} La integración con modelos de lenguaje de gran escala fue desarrollada con soporte para dos proveedores: OpenAI, con el modelo \textit{GPT-5.4 Nano}, y Google, con el modelo \textit{Gemini 2.0 Flash}, siendo el proveedor y modelo a utilizar configurables por empresa.
    \item \textbf{Canales de comunicación:} Para el canal de WhatsApp se integró la API de WhatsApp Business de Meta, este permite recibir y enviar mensajes en tiempo real. Ademas, el sistema cuenta con un widget web embebible que las empresas pueden insertar en su propio sitio web como canal adicional de atención al cliente.
\end{itemize}

\subsubsection{Patrones de Diseño}
\label{subsubsec:patrones_diseno}

El sistema fue desarrollado siguiendo distintos patrones de diseño que facilitan la organización, mantenimiento y escalabilidad del código.

El patron principal utilizado es el \textbf{Modelo-Vista-Controlador (MVC)}, propio del framework Laravel. En este patron, los modelos se encargan de la interaccion con la base de datos, los controladores gestionan las solicitudes entrantes y coordinan la logica del sistema, mientras que los componentes de React actuan como la capa de presentacion que el usuario visualiza.

Para la lógica de negocio mas compleja se implemento una \textbf{capa de servicios}, separando esta responsabilidad de los controladores. Dentro de esta capa destaca el servicio del asistente de ventas, que centraliza la interaccion con el modelo de IA: construye el contexto que se le envia, recupera el historial de la conversacion y valida las respuestas generadas antes de entregarlas al cliente. Estas validaciones, conocidas como \textit{guardrails}, aseguran que las respuestas del modelo sean coherentes con el catalogo de la empresa y no contengan informacion fuera de contexto.

Adicionalmente, se implementó el \textbf{patron de interfaz} para la integracióm con los proveedores de IA, lo que permite al sistema cambiar de proveedor sin afectar la logica del asistente de ventas. Por ultimo, se utilizaron \textbf{middlewares} para validar las solicitudes entrantes en los distintos canales de comunicacion, verificando la autenticidad de cada petición antes de que esta fuera procesada.

\subsubsection{Estructura del Código}
\label{subsubsec:estructura_codigo}

El código del sistema esta organizado siguiendo las convenciones de Laravel, manteniendo una estructura clara y predecible. En el directorio \texttt{app/} se encuentran los modelos, controladores, middlewares y servicios del backend, estos ultimos agrupados por dominio funcional dentro del directorio \texttt{app/Services/}. Los servicios relacionados con la inteligencia artificial se encuentran en su propio subdirectorio, separados del resto de la lógica del sistema.

En cuanto al frontend, los componentes y paginas de React se encuentran dentro del directorio \texttt{resources/js/}, organizados por tipo de elemento. Las paginas del panel administrativo, los componentes reutilizables y la configuracion de estilos se mantienen separados, facilitando la navegación y el mantenimiento del código.

Las migraciones de base de datos se encuentran en el directorio \texttt{database/migrations/}, donde cada archivo representa un cambio especifico en el esquema de la base de datos, permitiendo un control versionado de la estructura de la misma.

Los sistemas de información constituyen un conjunto organizado de recursos —personas, datos, procesos y tecnología— que interactúan para recolectar, procesar, almacenar y distribuir información relevante dentro de una organización. Su propósito principal es apoyar la toma de decisiones, la coordinación y el control, así como facilitar el análisis y la visualización de información estratégica \cite{laudon2020, stair2018}. En el contexto actual, caracterizado por la digitalización y la globalización, los sistemas de información han evolucionado hacia plataformas integradas que permiten la gestión eficiente del conocimiento y la automatización de procesos empresariales \cite{turban2019}. Además, el uso de tecnologías emergentes como la inteligencia artificial y el análisis de datos ha ampliado sus capacidades, permitiendo generar valor a partir de grandes volúmenes de información \cite{davenport2018}.

Por otra parte, la implementación de sistemas de información implica retos importantes relacionados con la alineación estratégica, la seguridad de la información y la gestión del cambio organizacional. Es fundamental que estos sistemas estén alineados con los objetivos del negocio para maximizar su impacto y retorno de inversión \cite{ward2016}. Asimismo, la protección de datos y la ciberseguridad se han convertido en aspectos críticos debido al incremento de amenazas digitales \cite{whitman2018}. Finalmente, el éxito de un sistema de información depende en gran medida de la aceptación por parte de los usuarios y de una adecuada gestión del cambio, lo que requiere capacitación, comunicación efectiva y liderazgo organizacional \cite{heeks2006}.
